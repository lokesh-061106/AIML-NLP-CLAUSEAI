# ClauseGuard

Explainable, non-LLM legal text simplification framework.

## Pipeline

Document Upload -> Text Extraction -> Graded Simplification -> Preservation Checking -> Readability Analysis -> Extractive Summary -> Legal Glossary

## Levels

Skilled - 6 approved rules
Intermediate - 10 approved rules
Basic - 14 approved rules

## Run

pip install -r requirements.txt
streamlit run app.py

ClauseGuard does not replace legal review.
